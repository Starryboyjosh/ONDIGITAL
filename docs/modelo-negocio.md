# ONDIGITAL — Modelo de Negocio

> **Todo lo Vital es Digital.**

---

## Quiénes somos

ONDIGITAL es una **micro-empresa hondureña** formada por un equipo de estudiantes con
mentalidad de producto, nacida como proyecto de graduación y construida como una empresa
real, no como un ejercicio académico.

No somos una fábrica de páginas web.

No entregamos plantillas.

Nos convertimos en el **departamento tecnológico** de cada cliente.

---

## Visión

Nuestro objetivo no es desarrollar únicamente un sistema o una base de datos.

Creamos **soluciones digitales hechas completamente a la medida**, diseñadas para adaptarse
a la forma en que opera cada empresa.

Cada implementación debe:

- Mejorar procesos.
- Reducir el trabajo manual.
- Automatizar tareas.
- Centralizar toda la información del negocio en una única plataforma.

Y el sistema no se queda quieto: **evoluciona junto con la empresa** mediante mejoras
continuas, nuevos módulos e integración de nuevas tecnologías.

---

## Qué desarrollamos

Cada proyecto se diseña específicamente para el negocio del cliente. **No existen plantillas
fijas.** Analizamos los procesos internos y construimos una solución alrededor de ellos.

Un sistema puede incluir módulos como gestión de clientes, CRM, agenda, facturación,
inventario, compras, recursos humanos, caja, reportes, dashboard ejecutivo, gestión
documental, automatizaciones, integraciones, APIs y módulos completamente personalizados.

### La referencia: Credental

**Credental** es software desarrollado específicamente para clínicas odontológicas, con
funcionalidades que solo un dentista necesita: diagrama dental, historial clínico,
tratamientos, agenda médica, facturación, gestión de pacientes, inventario odontológico y
reportes especializados.

Esa es la filosofía que replicamos para **cualquier industria**: cada empresa recibe un
sistema construido alrededor de sus propios procesos.

## La paradoja: a la medida, pero modular

Cada sistema es único por fuera. Por dentro, todos comparten una **arquitectura modular** y
una **biblioteca de módulos reutilizables**.

Esto es lo que hace posible entregar software verdaderamente personalizado a un precio de
suscripción: no empezamos desde cero en cada proyecto, **ensamblamos y adaptamos**.

Módulos reutilizables de la plataforma:

| | | |
|---|---|---|
| Usuarios | Roles | CRM |
| Inventario | Facturación | Reportes |
| Dashboard | Recursos Humanos | Compras |
| Proveedores | Agenda | Caja |
| Auditoría | API | Notificaciones |
| Automatizaciones | Gestión documental | Integraciones |

Cada módulo se adapta después al negocio del cliente. Esto reduce tiempos de desarrollo y
facilita el crecimiento de la plataforma.

## Vito — el asistente empresarial

La pieza de inteligencia de ONDIGITAL se llama **Vito**.

> Eco de *"lo **Vit**al"*: la inteligencia que vuelve digital lo esencial del negocio.

**Vito no es un chatbot.** Es un asistente empresarial que vive **sobre los datos reales del
propio negocio** y entiende su operación. Tres capacidades:

### 1. Consultas inteligentes

Preguntas en lenguaje natural, respondidas con los datos del negocio:

- ¿Cuánto vendimos este mes?
- ¿Quién es nuestro mejor cliente?
- ¿Qué clientes tienen pagos pendientes?
- ¿Qué productos necesitan reposición?
- ¿Qué empleados fueron más productivos?

### 2. Automatización inteligente

Vito ejecuta trabajo, no solo conversa: genera reportes, crea cotizaciones, redacta correos,
resume expedientes, clasifica documentos, analiza datos, automatiza procesos repetitivos y
genera recomendaciones.

### 3. Inteligencia de negocio

Indicadores, estadísticas, predicciones, tendencias, alertas y recomendaciones para la toma
de decisiones.

### Vito en los sistemas que ya existen

Vito no es un producto aparte: se conecta a los módulos del cliente. Dos demostraciones con
nuestros propios sistemas:

**En OnStock (gestión de inventario y ventas):**

- "¿Qué productos están por agotarse?"
- "¿Cuánto vendí esta semana y cuál fue mi margen?"
- "Genera la orden de compra de lo que falta."
- "¿Qué producto se mueve más lento?"

**En Credental (agenda y operación dedicada/clínica):**

- "¿Qué citas tengo mañana?"
- "Resume el expediente del paciente."
- "¿Qué pacientes tienen saldo pendiente?"
- "Redacta el recordatorio de cita por WhatsApp."

Mismo asistente, dos negocios distintos: porque Vito se adapta a los módulos, igual que la
plataforma se adapta al negocio.

### Vito es tuyo, no de un tercero

El cliente nunca ve "ChatGPT", "Claude" ni el nombre de ningún proveedor. Pregunta a **Vito**
y **Vito responde**. El motor de IA es un detalle de implementación: puede ser una API en la
nube elegida por nosotros o un modelo corriendo **localmente en el servidor del propio
cliente**, sin que cambie la experiencia. Así la inteligencia se siente parte del negocio —no
un servicio externo pegado encima— y la operación nunca queda atada a un solo proveedor.
